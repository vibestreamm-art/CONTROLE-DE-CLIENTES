# Controle de Clientes

Aplicativo para organizar clientes, vendas, pagamentos e contas a receber de forma simples e prática.

## Objetivo

Facilitar o controle financeiro e o gerenciamento de clientes, permitindo acompanhar vendas, pagamentos recebidos e valores pendentes.

## Funcionalidades principais

- Cadastro de clientes.
- Nome, telefone, endereço e observações.
- Registro de vendas e compras.
- Histórico de movimentações por cliente.
- Registro de pagamentos recebidos.
- Controle de valores pendentes.
- Datas de vencimento.
- Identificação de pagamentos atrasados.
- Painel com resumo financeiro.
- Alertas de vencimentos.

## Funcionalidades futuras

- Integração com WhatsApp.
- Envio automático de lembretes de pagamento.
- Envio de cobranças e faturas.
- Integração com Pix.

## Compatibilidade

O aplicativo terá como objetivo funcionar em celulares Android, incluindo Android 10.
